# OUB — Organizational Utility Benchmark

OUB complements PBM.

PBM measures platform outcome and execution efficiency on bounded deterministic work. OUB is designed for tasks where organizational qualities may matter: independent investigation, disagreement preservation, skeptical review, durable continuity, and coordination under evolving evidence.

The comparison unit remains the platform. Desktop and Codex Room receive the same mission, equivalent starting evidence, the same completion criteria, and the same deterministic grader. Neither platform is told how many agents to use or how to organize its work.

OUB v1 begins with a compact forensic task intended to require roughly 10–15 minutes of capable-model work per platform rather than long continuous runs that would consume a large fraction of the principal's usage allotment.

See `v1/PROTOCOL.md` for the historical O1 protocol. OUB v2 resumes I-028 under `v2/PROTOCOL.md`. The three-task external sample is frozen in `v2/SAMPLE.md` / `v2/sample.json`, passed deterministic sanity validation in Phase 3, and now has an explicit naturalistic platform harness described in `v2/README.md`. `CURRENT` remains `v1` until the v2 mechanical dry-run gate is complete.
