# OUB v1

OUB v1 is the first organizational-utility benchmark slice.

## O1 — Competing root causes

`o01-competing-root-causes` is a compact forensic incident investigation. The workspace contains a payment-worker implementation plus operational evidence. Several explanations are initially plausible. A full-credit result must identify the causal chain that explains the duplicate charges and reject the major alternatives with evidence.

The task deliberately requires no implementation changes. The measured work is investigation, synthesis, evidence discipline, and falsification of competing hypotheses.

Target capable-model runtime: approximately **10–15 minutes per platform**.

The target is a planning budget, not a validity cutoff. Actual time and token usage are measured rather than forced.

OUB v1 does not claim that one task is sufficient to validate Codex Room's utility. O1 is the first low-cost test of the specific hypothesis that independent organizational reasoning can improve forensic diagnosis when premature convergence is costly.
