# Security and Support

Codex Room is retired experimental software.

The project is preserved for local experimentation, study, and modification. It is not actively maintained as a production service.

- Do not expose the local Codex Room server directly to untrusted networks.
- Do not treat the repository as receiving ongoing security patches or dependency maintenance.
- Runtime data under `data/` may contain Room content and provider/runtime metadata and should be handled as private local data.
- Generated output under `output/` may contain benchmark evidence or other local artifacts and is intentionally excluded from version control.
- Review current dependency and Codex runtime behavior before using the project in any sensitive environment.

No security SLA or guaranteed response channel is provided for this retired project.
